# Базовый билет распродан, 06.11.2026

По запросу пользователя закрыт только базовый билет участника €80. В RU/DE каталоге мероприятий, верхней карточке страницы игр и блоке состава билетов радиокарточка выключена нативным disabled, показывает «Распродано» / «Ausverkauft» и неактивное оформление. VIP €180 остаётся выбранным и доступным; ведущие и Нюрнберг не закрыты.

Общий переключатель `BASIC_TICKETS_SOLD_OUT` находится в `src/lib/ticket-availability.ts`. Серверный каталог закрывает `guest` и исторический псевдоним `guest_early`. Новые заказы и котировки, включая промокоды, возвращают HTTP 409 sold_out до создания заказа или обращения к провайдеру. Каталог диалога не содержит закрытый билет; сообщения устаревшего клиента также обрабатывают sold_out. Не используется event_archived, поскольку мероприятие продолжается.

Старые заказы не отменяются и не пересчитываются. Обработчики подтверждений Stripe/PayPal, возвраты и выгрузка оплаченных заказов в Google Sheets сохранены. Остатки билетов автоматически не считаются; для открытия базового тарифа требуется изменить общий переключатель и опубликовать.

75/75 серверных тестов прошли, включая запрет новых покупок обоими провайдерами и всеми типами промокодов, отсутствие лишних записей, доступность VIP и подтверждение старых заказов Stripe/PayPal после закрытия. Старые тестовые фикстуры явно моделируют доступный базовый билет для проверки остальных платёжных сценариев. Отдельный тест проверяет фактическое опубликованное состояние каталога по умолчанию.

Локально прошли 27 актуальных браузерных сценариев. 13 сценариев оформления промокодов на базовый билет условно пропускаются, пока он распродан; после открытия тарифа они снова запускаются. Один прежний сценарий клика по базовой карточке исправлен с учётом её намеренного disabled и успешно повторён; стрелка клавиатуры не выбирает распроданный тариф. Два опубликованных сценария проверяют RU/DE, мобильную и настольную версии, каталог/детальную страницу, доступность VIP и запрет открытия базового билета через изменённый DOM. Шесть безопасных API-проверок опубликованного сайта вернули 409 sold_out; котировка VIP вернула €180. Для проверок новых заказов передавались только ticket/provider без персональных данных, полноценные покупки не создавались. Изображение опубликованной карточки визуально проверено. Astro check: 0 ошибок/предупреждений, одна прежняя подсказка consent; build 24 страницы.
