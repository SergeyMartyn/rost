# Подтверждённые оплаты в Google Sheets

Рабочая таблица: [Tickets](https://docs.google.com/spreadsheets/d/1xpuaUoMxUgZ5N3-mXZCPeaT2QdzXznHrQxrAiKPWQAk/edit).

## Куда приходят оплаты

- Участники игр и ведущие: `07.11.2026 - TI_München`.
- Встреча в Нюрнберге: `12.12.26 - Nuernberg`.
- Исторические оплаты Регенсбурга: скрытый лист `10.10.26 - Regensburg`.

Источник подтверждения: существующая серверная проверка Stripe/PayPal. Создание заявки или переход на страницу успеха не считаются оплатой.

Первые девять столбцов совместимы с прежним принимающим Apps Script. H содержит фактически полученную сумму, I содержит `paid`. Для новых регистраций ведущих добавлены J:P:

| Столбец | Значение |
| --- | --- |
| J | Полная стоимость участия |
| K | Остаток к оплате |
| L | Номер стола, либо пусто, если поздняя оплата поступила без свободного стола |
| M | Предоплата или полная оплата |
| N | Формат ведущего |
| O | Медиапакет |
| P | Название игры |

Пример стандартного участия с предоплатой: H=50, J=249, K=199, M=Предоплата. Оплаченный стол хранится бессрочно, включая предоплату. Правила бронирования не менялись.

## Доставка и восстановление

Расширение для промокодов, подготовлено 21.10.2026: Q «Базовая цена, €», R «Скидка, %», S «Скидка, €», T «Промокод», U «Акция», V «Источник кода». Заголовки записаны и проверены на всех трёх существующих листах, прежние данные не менялись. В H по-прежнему фактически оплаченная сумма. Новая строка обычного билета с FAMILY10T: H=144, Q=160, R=10, S=16, T=FAMILY10T, U=Семейная, V=Тимур, W=2, X=имя второго участника. J:P в строках участников пустые; для ведущих новые колонки пустые. И непосредственная отправка, и восстановление через cron используют сохранённые значения заказа.

`worker/sheets.ts` отправляет данные после подтверждения оплаты через `waitUntil`. Миграция `0003_sheet_exports.sql` добавляет только журнал доставки. Существующий минутный cron подбирает оплаченные заказы/регистрации без подтверждённой доставки, включая исторические записи. Неоплаченные заявки не отправляются.

Успех требует HTTP 2xx и точного ответа `ok`. `forbidden`, HTML-ошибка, тайм-аут и HTTP-ошибка вызывают повтор с задержкой от минуты до часа. После успешной доставки повторной отправки нет. Истёкшая двухминутная блокировка восстанавливается автоматически. При неоднозначном сетевом результате Apps Script устраняет дубли по ID заказа в столбце B. В журнале нет дополнительных копий контактных данных, токенов или ответа Google.

Для новых инсталляций используется `docs/google-sheets-apps-script.gs`. В текущей рабочей таблице заголовки расширены через Google Sheets, а лист Нюрнберга создан заранее. Изменённый файл `.gs` локальный; удалённый Apps Script не перепубликовывался. Действующий обработчик совместим с более длинными строками, что необходимо сохранить при его последующих правках.

Возвраты, ручные изменения таблицы и доплата остатка по отдельной внешней ссылке не синхронизируются этим изменением. Здесь автоматизированы подтверждённые оплаты текущих форм сайта: участники, полное участие ведущего и предоплата ведущего.
