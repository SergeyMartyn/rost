## 3. Контракт сайта с GTM (что должен сделать код сайта)

Сайт реализует по `Consent Banner 1.md` (разделы 7, 8, 10, 11, 15) и эталону из `Consent Banner 2.md` (часть VI):

1. **До выбора посетителя и после отказа** GTM не загружается, запросов к Google нет, `<noscript>` и стандартный сниппет GTM в `<head>` не используются (R-7.1–R-7.3). GTM подключается программно из кода баннера.
2. **GTM грузится, только если разрешена «Статистика» или «Маркетинг»** (R-7.8).
3. **Consent Mode: только Basic** (R-7.4). Перед загрузкой контейнера в `dataLayer` кладётся `consent default` со значениями из сохранённого выбора:

| Consent type | Значение |
|---|---|
| `analytics_storage` | `granted`, если разрешена «Статистика», иначе `denied` |
| `ad_storage`, `ad_user_data`, `ad_personalization` | `granted`, если разрешён «Маркетинг», иначе `denied` |
| `functionality_storage`, `personalization_storage` | `denied` |
| `security_storage` | `granted` |

4. **События категорий** (имена и поля должны совпадать с GTM буквально):

```js
// «Статистика» разрешена — на каждой загрузке страницы с сохранённым выбором и при первом решении
window.dataLayer.push({ event: 'consent_statistics_granted', consent_statistics: 'granted' });

// «Маркетинг» разрешён — только если маркетинговые сервисы вообще есть
window.dataLayer.push({ event: 'consent_marketing_granted', consent_marketing: 'granted' });
```

5. **При изменении выбора**: `consent update` и перезагрузка страницы (R-11.4); при отзыве удалить cookies `/^_ga/` (для «Маркетинга» — `_fbp`, `_fbc`, `/^_gcl/`, если такие сервисы появятся).
6. **Если сайт с переходами без перезагрузки страницы (SPA)**: добавить отдельное событие просмотра страницы и соответствующий триггер и тег GA4 в GTM. Для многостраничного сайта (Astro и т. п.) события категорий уходят на каждой странице, и GA4 засчитывает просмотр (R-8.5).
7. Внешние ресурсы (шрифты, карты, видео, CDN-библиотеки) грузятся только с собственного домена или через facade по клику (R-7.1, раздел 9).
8. Автовставки хостинга выключены (Cloudflare Web Analytics, Zaraz, Rocket Loader) — если хостинг Cloudflare (R-7.11).

2. Ответственный (Impressum): название, адрес, email, телефон.
3. Языки сайта и язык по умолчанию; адреса Impressum и Datenschutzerklärung на каждом языке.

## 6. Приёмка

Перед публикацией контейнера GTM выполнить R-16.1–R-16.3 из документа 1:
- в чистом браузере до выбора нет запросов к `googletagmanager.com`, `google-analytics.com`, `analytics.google.com`, нет cookies `_ga*`;
- «Только необходимые»: запросов нет;
- «Статистика»: GTM и GA4 загружены, `analytics_storage` = `granted`, `ad_*` = `denied`;
- Tag Assistant: `consent default` распознан до первого тега, GA4 срабатывает только на `consent_statistics_granted`;
- после публикации контейнера и сайта повторить сетевой аудит на рабочем домене.
