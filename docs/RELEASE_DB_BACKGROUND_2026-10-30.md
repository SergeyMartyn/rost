# Сокращение фоновых обращений к D1, 30.10.2026

По согласованию с пользователем обе фоновые задачи переведены с каждой минуты на каждые пять минут: `*/5 * * * *`. Удалено повторное создание семи столов в `releaseExpiredHostHolds`; их первичное создание остаётся в миграции `0002_host_registrations.sql`. Перед публикацией в production подтверждены все семь столов.

Пустой проход выполняет два UPDATE просроченных неоплаченных заявок/столов и один SELECT недоставленных оплат. Расчёт постоянного фона: 3 × 12 × 24 = 864 SQL-запроса в сутки вместо 4 × 60 × 24 = 5760, сокращение на 85%. Это расчёт фоновых запросов при отсутствии работы; обращения посетителей, подтверждения оплат и повторные доставки добавляются отдельно. Фактическая экономия прочитанных строк зависит от данных и плана запросов.

Срок неоплаченной заявки остаётся 31 минута. Очистка по расписанию происходит при следующем проходе, номинально до пяти минут позже срока; выполнение Cloudflare может задерживаться. Синхронная очистка при открытии формы, запросе статуса и попытке бронирования сохранена. Оплаченная предоплата сохраняет стол без ограничения по времени. Подтверждённые оплаты отправляются в Sheets сразу; только резервное восстановление пропущенных/неуспешных отправок запускается каждые пять минут. Сроки повторов внутри журнала доставки сохранены, попытка происходит после наступления next_attempt_at на очередном проходе.

База: production `rost-orders`, `3172652b-2274-4ce0-bf39-c74f94a58ee9`. Схема, платежи, строки Sheets и секреты не изменяются. Bookmark до публикации: `00000073-00000002-00005114-6022c61679f58b8d007775c84d8ed4c0`.
