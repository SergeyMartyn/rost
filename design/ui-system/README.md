# Локальные снимки UI

Актуальные снимки после замечаний пользователя 20.10.2026:

- `ui-*`: основные страницы на RU/DE при 390 и 1440px.
- `consent-*`: компактный баннер на 320/390/768/1440px.
- `menu-*`: мобильное меню.
- `value-*`: новые блоки участников и ведущих с временной иллюстрацией 4:3. Фиксированные элементы скрыты только при съёмке самого блока.
- `first-practitioner-390.png`: первая карточка ведущей до hover.

Остальные PNG без этих префиксов относятся к предыдущему этапу стандартизации и могут показывать уже удалённые Breadcrumbs. Это исторические снимки, не текущий эталон. Изменения опубликованы 20.10.2026. Снимки проверки публичного домена сохранены в production-2026-10-20/.
